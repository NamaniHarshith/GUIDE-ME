# GUIDE ME 👁️‍🗨️ – Assistive AI App for the Visually Impaired


## 📱 Overview

**GUIDE ME** is an AI-powered assistive application built to empower visually impaired individuals by helping them navigate the world more independently.

> Real-time object detection, currency recognition, text reading, and emergency assistance – all in one smart solution.

---

## 🚀 Features

- 🧠 **Object Detection** – Detects objects in real time using deep learning.
- 💵 **Currency Detection** – Recognizes various denominations accurately.
- 📝 **OCR** – Reads out text from documents, signs, and more.
- 🆘 **SOS Function** – Sends emergency messages using gestures or voice.
- 🎙️ **Voice & Gesture Commands** – Completely hands-free interaction.

---

## 🛠️ Tech Stack

- `Python` (Flask API)
- `Flutter` (Cross-platform frontend)
- `TensorFlow`, `OpenCV` (AI/ML)
- `Twilio API` (For SOS alerts)
- `Firebase / GCP` *(optional for backend services)*
